# ADR-0002：模型提取证据，确定性代码评分，高风险动作人工确认

- 状态：接受
- 日期：2026-07-30
- 决策人：产品、业务与技术负责人

## 背景

招聘推荐影响候选人权益。让模型自由评分或直接执行淘汰、邀约、录用等动作，会带来不稳定、不可解释、偏见和合规风险。

## 决策

- 模型用于需求理解、内容草拟、语义召回、证据提取和非最终性建议。
- 学历、技能、地点等硬条件由显式规则执行。
- 评分维度、权重、阈值和公式由版本化评分卡定义，并由确定性代码计算。
- 每项分数必须关联原文证据、来源位置、规则版本、模型版本和置信度。
- 岗位发布、候选人名单、淘汰决定、录用决定和 Offer 审批必须由具备权限的人员确认。
- 受保护属性不得进入匹配与评分特征。

## 结果

相同输入与规则能够得到稳定分数，推荐可以复核，模型升级不会隐式改变业务标准。系统需要额外建设证据结构、规则版本、人工任务和审计记录。

## 备选方案

- 模型直接输出总分：实现快，但无法保证稳定映射和可解释性。
- 全规则匹配：稳定，但难以处理简历中的语义表达和非结构化证据。

## 复审条件

不存在取消人工门禁的默认条件。任何门禁变化必须经过业务、安全和法律合规评审，并新增 ADR。
