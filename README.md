# 知聘 · 招聘智能体体验平台

面向央国企招聘场景的可解释招聘智能体原型。产品以独立平台形式跑通岗位方案、人才搜索、面试协同、综合评价、知识维护和运行审计，再通过适配层接入不同客户的招聘系统。

## 本地运行

```bash
npm install
npm run dev
```

## 当前演示范围

- 招聘任务驾驶舱与人工审批节点
- 岗位 JD、任职标准与固定评分卡的生成和人工确认
- 人才库检索、固定评分卡与简历原文证据
- 在线面试邀约、状态回收与评价生成
- 综合评价与风险复核
- 岗位知识、人才画像、制度流程的分类维护
- 智能体执行、知识引用与人工操作审计

演示数据均为虚构数据，不包含真实候选人信息。
