# 知聘 · 招聘智能体体验平台

面向央国企招聘场景的可解释招聘智能体前端演示产品。平台以独立应用形式跑通岗位方案、人才搜索、面试协同、综合评价、知识维护和运行审计，后续可通过 API 或客户侧适配层接入不同招聘系统。

## 本地运行

```bash
npm install
npm run dev
```

生产构建检查：

```bash
npm run build
```

## 当前演示范围

- 招聘任务驾驶舱、阶段推进、搜索筛选、编辑和归档
- 工作台按阶段展示人工门禁、自动人才检索与实时轮播的智能体执行动态
- 新建招聘任务并自动生成岗位方案，任务数据按岗位独立持久化
- 岗位 JD、任职标准与固定评分卡的生成和人工确认
- 人才库检索、阈值和权重调整、候选名单确认、简历原文与评分证据
- 在线面试邀约、批量提醒、截止时间维护、状态回收和转写查看
- 综合评分、风险复核、候选人级人工结论和报告导出
- 岗位知识、人才画像、制度流程的新增、筛选、编辑、版本和归档维护
- 智能体执行、知识引用与人工操作审计，支持任务范围筛选和 CSV 导出
- 全局搜索、通知中心、企业空间、帮助中心和响应式移动端布局

演示数据均为虚构数据，不包含真实候选人信息。任务、候选名单、面试状态、评价结论、知识资料和审计日志保存在当前浏览器的 `localStorage` 中。
